# מרכז ניהול תזונה חכם, מאגר מתכונים ותפריט שבועי (Meal Prep)

מערכת מלאה וקלת-משקל לניהול תזונה, מאגר מתכונים אישי, מעקב מזווה ורשימת קניות, ותכנון שבועי עם אינטגרציות מובנות ל-**Listi** ול-**The Healing Cabin**.

---

## 1. מבנה הנתונים (Database & Collections)

הפרויקט עושה שימוש ב-SQLite מובנה (Node.js `node:sqlite` Native) ללא תלות בספריות צד שלישי:

### א. מאגר מתכונים (`recipes`)
- **שדות טקסט**: `title` (כותרת המנה), `description` (תיאור), `instructions` (הוראות הכנה), `source_url` (קישור למקור/ייבוא).
- **שדה מדיה**: `image_url` (תמונת המנה).
- **שדות מספריים**: `prep_time_minutes` (זמן הכנה), `calories` (קלוריות), `protein_grams` (כמות חלבון), `difficulty` (רמת קושי: קל / בינוני / קשה).
- **מצרכים**: `ingredients` (מערך JSON של מצרכים עם כמויות ויחידות מידה).
- **תגיות (Tags)**: `tags` (מערך JSON של תגיות לסינון מתקדם).

#### 🏷️ תגיות מערכת מובנות מראש:
1. עתיר חלבון
2. דל סוכר
3. מתאים לנינג'ה קרימי
4. מתאים לנינג'ה סלאשי
5. צמחוני
6. מנות דגים (ללא בקר ועוף)
7. ללא כוסברה
8. ללא סלטים

### ב. מזווה ורשימת קניות (`pantry_groceries`)
- `item_name` (שם המצרך - ייחודי).
- `quantity` (כמות ויחידת מידה).
- `status` (סטטוס: `'במזווה'`, `'חסר'`, `'ברשימת קניות'`).
- `updated_at` (חותמת זמן עדכון אחרון מ-Listi).

### ג. תפריט שבועי (`weekly_plan`)
- `day_of_week` (יום בשבוע: ראשון עד שבת).
- `meal_type` (סוג הארוחה: בוקר, ביניים, צהריים, ערב וכו').
- `recipe_id` (קישור למתכון מתוך מאגר המתכונים).
- `notes` (הערות Meal Prep).

## 2. ממשקי API ואינטגרציות

### אינטגרציה עם Listi (קבלת מלאי / Webhook)
- **נתיב**: `POST /api/integrations/listi`
- **פעולה**: קולט רשימת מצרכים מאפליקציית Listi ומבצע Upsert למזווה ולרשימת הקניות.
- **מבנה הבקשה לדוגמה**:
```json
[
  { "itemName": "פילה סלמון", "quantity": "400 גרם", "status": "במזווה" },
  { "itemName": "חלב שקדים ללא סוכר", "quantity": "1 ליטר", "status": "ברשימת קניות" }
]
```

### אינטגרציה עם The Healing Cabin (דחיפת תפריט מאושר)
- **נתיב**: `POST /api/weekly-plan/approve-and-push`
- **פעולה**: מופעל לאחר אישור התפריט השבועי.
- **אבטחה וסינון**: שולח אך ורק את השדות המורשים (ללא רשימת המצרכים ואופן ההכנה!):
```json
{
  "source": "NutritionRecipePlanner",
  "event": "WEEKLY_PLAN_APPROVED",
  "timestamp": "2026-11-12T12:00:00.000Z",
  "recipes": [
    {
      "title": "גלידת חלבון וניל לנינג'ה קרימי",
      "description": "גלידת וניל קרמית במיוחד, עתירת חלבון וללא תוספת סוכר.",
      "calories": 190,
      "protein_grams": 32
    }
  ]
}
```
